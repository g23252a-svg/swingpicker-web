# 포켓시티 — 스마트폰 도시 건설 시뮬레이션

폰 브라우저에서 바로 돌아가는 도시 건설 시뮬레이션 게임입니다. 설치 없이 링크만으로 플레이할 수 있고,
홈 화면에 추가하면 앱처럼 전체 화면으로 뜨며 **비행기 모드에서도 실행**됩니다.

이 디렉터리는 저장소의 파이썬 애플리케이션(SwingPicker)과 완전히 분리된 정적 파일 묶음입니다.
빌드 도구, 패키지 의존성, 서버 코드가 전혀 없습니다.

## 실행 방법

정적 파일이라 아무 웹서버에나 올리면 됩니다.

```bash
cd game/citysim
python3 -m http.server 8000
```

폰과 PC가 같은 와이파이에 있다면 폰 브라우저에서 `http://<PC의_IP>:8000` 으로 접속합니다.
GitHub Pages, Netlify, Vercel 등 정적 호스팅에 그대로 올려도 동작합니다.

> 서비스워커(오프라인 캐시)와 홈 화면 설치는 `https://` 또는 `localhost`에서만 활성화됩니다.
> 평문 `http://<사설IP>` 로 접속하면 게임 자체는 정상 동작하지만 오프라인 캐시는 꺼집니다.

**홈 화면에 추가** — iOS Safari: 공유 버튼 → "홈 화면에 추가" / Android Chrome: 메뉴 → "앱 설치".

## 조작

| 동작 | 방법 |
|---|---|
| 지도 이동 | 도구를 고르지 않은 상태에서 한 손가락 드래그 (또는 언제나 두 손가락) |
| 확대·축소 | 두 손가락 오므리기/벌리기 |
| 건설 | 아래 팔레트에서 도구를 고르고 칸을 탭 |
| 연속 건설 | 도구를 고른 채 드래그 — 도로와 구역을 한 번에 여러 칸 |
| 철거 | 도구 ▸ 철거 (드래그로 여러 칸) |
| 칸 정보 | 도구 ▸ 살펴보기 후 탭 |
| 상태 겹쳐보기 | 상단의 전력 / 수도 / 오염 / 지가 |

## 게임 규칙

구역 한 칸이 건물로 자라려면 **① 도로에 접해 있고 ② 전기가 들어오고 ③ 물이 나와야** 합니다.
셋 중 하나라도 끊기면 몇 달 뒤 쇠퇴하고, 오래 방치하면 사라집니다.

레벨을 올리려면 그 칸의 **지가**가 충분해야 합니다. 지가는 공원·광장·치안·교육·의료가 올리고
오염과 범죄가 내립니다. 최고 레벨(Lv.3) 주거는 의료, 고급 상업은 교육 반경 안에 있어야 합니다.

상단 **RCI 막대**는 지금 무엇이 부족한지 알려줍니다. 오른쪽으로 차 있으면 그 용도를 더 지정할 때이고,
왼쪽으로 차 있으면 이미 과잉이라 지어도 비어 있습니다. 일자리가 없으면 주거 수요가 멈추고,
인구가 없으면 상업 수요가 생기지 않습니다.

적자가 나면 부채로 쌓이고 이자가 붙습니다. **시설을 강제로 철거당하지는 않습니다** —
발전소가 사라지면 도시 전체가 정전되어 회복이 불가능해지기 때문입니다.
부채에 빠졌을 때 철거는 자금이 없어도 가능하니, 도로와 시설을 줄여 유지비를 낮추면 됩니다.

소방서 반경 밖의 건물은 드물게 화재로 전소합니다. 도시가 커질수록 확률이 올라갑니다.

## 진행 단계

마을 → 읍(500명) → 시(2,000명) → 대도시(10,000명) → 광역시(50,000명).
학교는 400명, 병원은 900명, 광장은 1,500명, 태양광 발전은 3,000명부터 해금됩니다.

## 저장

플레이 상태는 브라우저 `localStorage`에 자동 저장됩니다(약 12개월마다, 그리고 앱을 벗어날 때).
같은 브라우저로 다시 열면 이어서 진행됩니다. 메뉴에서 수동 저장과 새 도시 시작도 가능합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `data.js` | 타일 종류, 건물 카탈로그, 밸런스 상수 |
| `sim.js` | 시뮬레이션 엔진 — 성장·수요·재정·오염. DOM에 전혀 의존하지 않음 |
| `render.js` | 캔버스 렌더러 — 카메라, 타일 그리기, 오버레이 |
| `ui.js` | HUD·팔레트·모달·토스트 |
| `game.js` | 입력 처리(터치/핀치), 게임 루프, 저장 |
| `sw.js` | 오프라인 캐시 |

`sim.js`는 브라우저 없이도 그대로 돌릴 수 있어 밸런스를 수치로 검증할 수 있습니다.

```js
global.window = global;
require('./data.js'); require('./sim.js');
const S = Sim.create();
Sim.build(S, 'road', 40, 32);
for (let m = 0; m < 240; m++) Sim.tick(S);
console.log(S.pop, S.money, S.happy);
```
