# v30 — Smart Exits: 데이터 근거 손절/목표가

> 2026-07-14 · "손절·목표가가 때려잡기식이 아니라 데이터 근거를 갖도록" 요구의 구현.

## 1. 문제 (측정)

실현 트레이드 감사: 손절 중앙값 **-15.0%** / TP1 중앙값 **+19.4%** / TP1 도달률 23%.

원인 (코드 추적):
- 손절 = ATR%×2.0에 **약세장 확대(시장폭<25 → ×1.4)**가 곱해지고 **상한 15%**에서 클램프
  → 폭락장 후보(ATR% 5~8%)는 전부 -15%로 수렴
- 목표가 = **손절폭×RR배수(2.0~3.0)** → 손절이 넓으면 목표도 같이 멀어짐 → 도달률 붕괴
- 손절된 트레이드의 **51%가 +5%를 먼저 찍고** -12~15%로 마감 (본전 보호 없음)

## 2. 검증 (청산 그리드 실험실)

게이트 통과 후보 851건 (진입 t+1 시가, 보유 10일, 왕복비용 0.22%),
train(2~5월) 선정 → OOS(6~7월) 확인, 64개 조합:

| 설계 | train 평균 | train p5(꼬리) | OOS 평균 |
|---|---|---|---|
| 현행 근사 (15%캡 · risk×2 · BE없음) | -0.83% | -15.2% | -7.28% |
| **v30 (스윙앵커 · 8%캡 · 3.5×ATR · BE+5%)** | **+1.03%** | **-8.2%** | **-4.06%** |

- BE+5%는 상위 8개 조합 **전부**에 포함 — 가장 확실한 단일 레버
- 8%캡은 평균을 해치지 않으면서 꼬리손실을 절반으로
- 실제 top3 픽 42건 재검: 평균은 대등(+1.5 vs +2.0), 꼬리 -8.2 vs **-15.3** —
  손절폭 절반 → 동일 계좌리스크로 포지션 ~2배 → 계좌 단위 기대수익 우위

## 3. 변경 (SSOT)
