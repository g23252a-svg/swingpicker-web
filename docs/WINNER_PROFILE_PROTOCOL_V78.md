## 루프

사용자 제안 그대로다: **매일 승률 높았던 종목의 특징 분석 → 특성 테스트 →
유의미하면 본 추천 개발에 편입.** 단, 과거 데이터를 뒤지는 방식(사후 선택)은
129개 신호 전멸로 이미 닫았으므로, 이 루프는 **선등록-전방누적**으로 돈다:

```
[선등록]  특징 12개 고정 (v1-20260831) · 문턱 고정 (아래)
   ↓ 매일 밤 (pipeline_finalize, 기록 전용)
[기록]    5일 창이 막 닫힌 코호트(~1,200종목)의 특징×실현수익 IC 1줄/특징
   ↓ 누적 (구조적으로 표본 외 — 오늘 등록한 특징은 내일 데이터로만 평가)
[1단계]   ≥40일 · HAC(5) p<0.05 · BH-FDR q=0.05 생존 · 전/후반 부호 일치
   ↓ 통과 시
[2단계]   v73 방식 그림자 레인 20 거래일 (표시 전용, 주문 없음)
   ↓ 생존 시
[3단계]   본선정 편입 — 사용자 승인. 코드가 결정하지 않는다.
```

## 왜 각 문턱인가 (전부 이 저장소의 실측 사고에서 나왔다)

| 문턱 | 막는 사고 |
|---|---|
| HAC(5) | HZ3 사건 — 겹침 창 순진 t p=0.0002가 HAC로 p=0.11 |
| BH-FDR q=0.05 | 12개를 재면 1개는 우연히 p<0.05가 나온다 |
| 전/후반 부호 일치 | A2 사건 — IS/OOS 부호 불일치를 무시할 뻔했다 |
| 실현수익 SSOT 재사용 | 종가수익으로 재면 손절·거래정지 처리가 사라진다 (저가=0 사건) |
| 수급 억 단위 확정 저장 | tv60 사건 — 원/억 혼용이 p=0.0009짜리 가짜 신호를 만들었다 |
| 그림자 레인 20일 | 백테스트는 탐색의 산물일 수 있다 — 발견 이후 표본만 오염이 없다 |
