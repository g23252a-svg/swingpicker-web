# 스윙 후보 화면과 수익 검증 패치

## 목표와 적용 범위

당일 종가로 후보를 분석하고 **다음 거래일 시가에 진입한 뒤 며칠 보유하는 스윙**이 목표다.
새 연구 모델의 기준은 진입일을 1일째로 세어 최대 5거래일 보유, 진입가 대비 -8% 손절,
갭 하락 시 실제 시가 체결, 왕복 비용·슬리피지 0.3% 가정이다. 비용은 실험 시나리오이며 세율 안내가 아니다.

기존 공식 매수의 지정가·수량·청산 규칙은 별도 계약이다. 새 연구 결과를 기존 주문 계획의
실현 성과와 합치지 않는다. 기존 alpha 엔진은 D+1 시가→D+6 종가의 상대순위 목표를 유지하고
이번에는 학습 라벨이 검증 구간까지 넘어가는 누수만 제거했다.

## 사용자가 보는 변화

- 오늘 탭의 맨 위에 다음 거래일 진입 후보와 종가·근거·공식 매수/관찰 구분을 표시한다.
- 기본 5개, 목록이 더 있으면 10개로 전환한다. 상세 화면으로 바로 이동한다.
- 보유 관리·매수 계획, 기존 성과, 연구 설명을 접어서 탐색한다. 보유 조치가 있으면 상단에 건수를 표시한다.
- 주요 탭은 오늘·종목·자산·시장·성과로 정리하고 나머지는 더보기에서 연다.
- 새 모델은 확률 정확도와 비용 후 수익 우위를 **모두** 통과해야 기본 후보 순위에 반영한다.
  실패하면 기존 엔진의 공식·관찰 선별을 유지하고 연구 순위는 접힌 영역에서만 보여 준다.
  연구 점수는 상대순위이며 수익 확률이 아니다.

## 실제 검증과 채택 결정

자료 기준은 저장소 main `d357251aaaa4e0513f8fc0291ba824fe9d675af1`의 2026-09-07 종가다.
137개 날짜별 OHLCV 캐시와 추천 모집단으로 53,549행·1,270종목의 패널을 만들었다.
유동성·특징 가용성·학습 기간을 적용한 공통 OOS는 2026-06-25~08-31의 46거래일, 13,901행이다.
다음 수익은 **결과를 관측할 수 있는 중첩 보유 코호트의 일별 평균**이며 계좌 누적수익이 아니다.
미확정 선택은 다른 종목으로 대체하지 않고 검증 실패 사유에 포함했다.

| 비교 | 상위 5개 비용 후 평균 | 비용 후 수익 적중률 | 선택 결과 미확정 |
|---|---:|---:|---:|
| 고정 확률 앙상블 | -2.68% | 28.37% | 8/230 |
| 고정 기대수익 회귀 대안 | -2.09% | 30.87% | 5/230 |
| 동일 날짜의 전체 적격 모집단 | -1.05% | 36.49% | 전체 결과 가용률 99.01% |

확률 모델 AUC는 0.374, 확률 오차(Brier)는 0.297로 과거 기저율 예측 0.262보다 나빴다.
상위 5개 비용 후 수익의 5일 블록 bootstrap 95% 구간은 -4.88%~-0.17%였다.
기대수익 회귀도 95% 구간 -4.05%~+0.53%로 수익 우위를 입증하지 못했다.
**두 모델 모두 기본 추천으로 채택하지 않았다.** 결과를 보고 문턱을 낮추거나 순위를 뒤집지 않았다.
회귀 비교는 첫 모델 실패를 본 뒤 한 고정 사양을 점검한 탐색 결과로, 독립 승인용 holdout이 아니다.

기존 alpha의 월별 누수 제거 감사도 상대순위와 절대 수익의 차이를 보여 준다.
80일 OOS에서 평균 일별 IC는 0.161→0.131, 상위 십분위 총수익은 -0.52%→-1.51%였다.
기존 alpha의 `validated`는 상대순위 검증이며 비용 후 수익 보장이 아니다.
이 수치는 사용자 계좌의 누적 수익 약 250만원을 재계산한 결과가 아니다.

## 데이터와 검증 방어

- 날짜별 추천 모집단을 사용하고 나중에 남은 종목만 과거에 소급하지 않는다.
- OHLCV의 최초 유효 관측과 그 자료를 확보한 날짜를 보존한다. 늦게 수집한 과거 가격으로 과거 특징을 만들지 않는다.
- 라벨 종료일과 실제 자료 확보일이 학습→보정→검증의 다음 구간보다 빨라야 한다.
- 학습 60일·보정 10일 이상을 누수 제거 **후** 다시 확인한다.
- 시간순 OOS에서 순위를 먼저 결정하고 나중에 결과를 결합한다. 손절 후 가격이 사라져도 이미 확정한 손실은 보존한다.
- 거래정지·가격 결측·체결 불가능한 가격제한·가격 불연속은 임의 체결이나 0% 수익으로 채우지 않는다.
- 확률 검증에는 OOS 40일, AUC≥0.53, 기저율 대비 Brier 개선, 상위 5개 적중률 우위≥3%p,
  보정 오차≤6%p, 선택 결과 완전성 등을 요구한다.
- 수익 검증에는 상위 평균 순수익과 같은 날짜 모집단 대비 초과수익의 블록 신뢰구간 하단이 모두 0보다 커야 한다.
- 예측과 검증 보고서를 하나의 원자적 JSON으로 읽고 종가 기준일이 다른 결과는 화면에 결합하지 않는다.
- 기존 alpha 보고서도 `purged_label_end_v1` 방식으로 재학습한 경우에만 검증 플래그를 사용할 수 있다.

## 실행과 후속 점검

야간 `pipeline_finalize.py`가 종가 데이터 준비 후 새 모델을 계산하고 `SWING_*` 표시 열을 저장한다.
모델 실패는 로그에 남기고 기존 공식 선별을 유지한다. 웹 요청 중에는 학습하지 않는다.

```bash
python scripts/build_swing_predictions.py --data-dir data --asof 20260907
python scripts/check_swing_performance.py --data-dir data --asof 20260907
python scripts/audit_swing_expected_return.py --data-dir data --asof 20260907 --output-dir /tmp
```

`swing_snapshot_latest.json`은 현재 표시용이며, `swing_snapshot_YYYYMMDD.json`은 첫 생성 결과를
보존한다. `generated_at_utc`로 내부 생성 시각이 장 시작 전인지 이후인지 구분한다.
`generated_before_entry_summary`와 `generated_after_entry_summary`는 이 내부 시각만을
기준으로 하며, 보고서는 `timing_basis=internal_generation_timestamp`,
`publication_verified=false`를 명시한다. GitHub 게시·프론트 노출 시각과 실제 매수 가능성은
이 생성 기록으로 입증하지 못하므로, 사전 공개된 실전 추천 성과로 해석하지 않는다.
재실행은 해당 날짜의 최초 순위를 덮어쓰지 않는다. 날짜별 파일의 상위 선택을 고정한 후 실제
가격 결과를 붙여 완료·보유 중·결과 누락을 구분하며, 연구 예측을 공식 체결로 간주하지 않는다.

`swing_validation_latest.json`과 `swing_oos_daily_latest.csv`는 검증 요약이다.
큰 합집합 캐시와 개별 OOS 행은 `data/.swing_cache/`의 재생성 가능한 자료로 git에 넣지 않는다.
외부 수집·알림·주문 없이 위 명령으로 감사할 수 있다. 이미 저장된 추천 모집단 밖의 전체 시장,
실제 체결량, 계좌별 수익은 이 자료만으로 추정하지 않는다.

새로운 후보를 채택하려면 이번 탐색 이후에 발표된 순위의 전방 성과가 추가로 필요하다.
다음 점검에서도 적은 완료 표본을 유의미한 수익 개선으로 단정하지 않는다.

## 코드 검증

전체 로컬 스위트의 기능 검증 2,266개가 통과했고 14개는 선택 의존성 등으로 건너뛰었다.
동시에 실데이터 감사 파일을 생성해 데이터 오염 감지 teardown 3건이 발생했으나,
파일 생성을 끝내고 해당 파일과 신규 스윙 테스트를 단독 재실행한 102개는 모두 통과했다.
계약·의존성/순환참조·silent exception 검사와 변경 Python 문법·diff 검사를 통과했다.
외부 운영 화면의 브라우저 상호작용 검증은 이 결과에 포함하지 않는다.
