# v27 — High-Probability Selection Patch

> 2026-07-14 · 최근 수익률 저조 문제에 대한 데이터 기반 개선 패치

## 1. 진단 (왜 수익률이 저조했나)

실현 트레이드 감사 대상: `data/backtest_top3_trades_20260714.csv` — 2026-02-26 ~ 2026-07-13, 일별 🏆 최강 Top1/Top3 픽 157건 (체결 기준).

| 지표 | 값 |
|---|---|
| 평균 손익 | **-2.7%/건** (EV -2.9%) |
| 승률 (TP1 선도달) | 22.9% |
| 손절률 | 56.1% |
| 손절폭 중앙값 | -15.0% / TP1 중앙값 +19.4% (RR 1.6 → 필요 승률 38%+) |

### 근본 원인 3가지

1. **점수-승률 역전.** ELITE_SCORE 60-70 구간 실측 승률 78% (+5.0%/건) vs 70-80 구간 32% (-4.4%), 80-90 구간 36% (-6.2%). LOSS 트레이드의 평균 rank_score(65.0)가 WIN(61.8)보다 높음 — **점수가 높을수록 확장(추격) 종목에 몰려 있었음.**
2. **확장 추격 미차단.** POC_GAP(볼륨프로파일 POC 대비 괴리) 구간별 실측:
   | POC_GAP | n | 평균 | 승률 |
   |---|---|---|---|
   | (0, 10] | 42 | -0.6% | 40% |
   | (10, 20] | 21 | **+6.8%** | **48%** |
   | (20, 30] | 10 | -7.0% | 20% |
   | (30, 50] | 24 | -6.3% | 12% |
   | 50+ | 56 | -5.9% | 23% |

   경계가 20에서 명확하게 꺾임. 그러나 기존 게이트 어디에도 POC_GAP 조건이 없었음.
3. **환율 절대레벨 CRITICAL 고착.** `fx_critical=1490` 절대 기준이 환율 1500원대 안착(재베이스) 이후 상시 발동 — 2026-03~07 run_meta 90건 중 56건 CRITICAL, 7월 top_pick 0건. 시장이 좋아도 나빠도 시스템이 동일하게 침묵 → 정보가치 0.

## 2. 패치 내용

### 게이트 (전 계층 일관 적용)

- **POC 확장 차단:** `POC_GAP ≤ 20` — `poc_gap_max_entry` (collector_config)
- **시장폭 하한:** `MARKET_BREADTH ≥ 35` — `breadth_min_entry` (기존 v3.9.24 `internal_weak<35` shadow 기준을 production으로 승격)
- 컬럼 누락/NaN → 통과 (legacy CSV 호환)

적용 지점:

| 계층 | 파일 | 적용 |
|---|---|---|
| TOP_PICK hard gate | `scoring_engine.py compute_elite_score` | POC 게이트 + `EXTENSION_BLOCK` 컬럼 |
| PRODUCTION_BUY | `services/recommendation_quality.py` | POC + 시장폭, 차단 사유 표기 |
| 백테스트/일별 픽 | `backtest_validation.py pick_top1/top3_codes` | POC + 시장폭 게이트, POC 오름차순 정렬 |
| UI 라벨 | `components/tab_stocks.py` | 게이트 탈락 시 `⚠️ 확장추격` (🔴) 강등 |

### 환율 레짐 판정 (`macro_filter.py`)

- CRITICAL = 레벨 ≥1490 **AND** 5거래일 상승률 ≥ +1.5% (급등 진행형)
- 레벨 높지만 안정/하락 = CAUTION ("고환율 레짐") — 방어는 시장폭 게이트가 담당
- 데이터 6행 미만이면 급등 취급 (보수적 폴백, 기존 동작 유지)

### 픽 정렬

게이트 통과 후보를 `POC_GAP` 오름차순(가치영역 근접 우선) → rank_score 보조로 정렬.
