# SwingPicker v26 Loss Defense

## 발견된 핵심 문제

1. 첫 화면의 Hero가 `TOP_PICK`만 보고 “오늘 매수 OK”를 만들 수 있었지만, 종목 탭의 공식 기준은 `TOP_PICK + BUY_NOW_ELIGIBLE`였습니다. 같은 CSV를 두 화면이 다르게 해석했습니다.
2. 일일 브리핑과 텔레그램은 공식 여부와 관계없이 ATTACK/ARMED 또는 상위 행을 발송했습니다. 공식 후보가 0개인 날에도 관찰 후보가 추천처럼 보였습니다.
3. 포트폴리오 교체는 공식 후보가 없으면 `DISPLAY_SCORE` 최고 종목으로 폴백했습니다.
4. 기존 ML 메타에는 시간순 검증 KPI의 상세치와 production 승인 여부가 없었는데도 ML 점수가 추천 점수에 반영됐습니다.
5. 실현성과 감사 스크립트가 Top-1과 Top-3에 동시에 들어 있는 동일 신호를 중복 집계했습니다.

## 새 추천 계약

```text
기존 TOP_PICK + BUY_NOW_ELIGIBLE
        ↓ (승격 불가, 거부만 가능)
진입등급 BUY + BUY_NOW_SCORE ≥ 70 + 비공격형 + GREEN 위험 + ATTACK
        ↓
MFI 70~88 + RES_RATIO_NEAR ≥ 0.13 + VWAP_GAP 4~14
        ↓
RR ≥ 1.30 + DISPLAY_SCORE ≥ 70 + 데이터/손실방어 이상 없음
        ↓
품질점수 최상위 1개만 PRODUCTION_BUY = 1
```

조건을 통과하지 못하면 `ACTION_DECISION`은 `WATCH` 또는 `CASH`, 권장 비중은 0입니다. 품질게이트는 기존 후보를 새로 매수 후보로 승격하지 않습니다.

## 실현성과 기준선

2026-07-10까지 Top-1/Top-3 중복을 제거한 307개 신호의 평균 순수익은 -3.25%, 승률은 25.08%였습니다. ML 점수와 실현수익의 Spearman 상관은 -0.038이고 2026년 6월은 -0.1263이어서 기존 ML은 production에서 제외했습니다.

- `ARMED`: 48건, 평균 -5.93% — 신규매수 차단
- `AGGRESSIVE`: 13건, 평균 -7.67% — 신규매수 차단
- `BUY_NOW_SCORE > 70`: 24건, 평균 +1.40% — 표본이 작아 단독 승격에는 쓰지 않고 필수 방어조건으로만 사용
- `MFI14 > 72.25`: 77건, 평균 +0.43% — 역시 다른 모든 조건과 함께만 사용

이 수치는 과거 데이터의 기술통계이며 미래 수익을 보장하지 않습니다. 새 정책의 실제 성과가 충분히 쌓이기 전에는 종목당 3~5%, 하루 신규 1종목 제한을 유지합니다.

## ML 승인 기준

데이터를 날짜순 학습 70% / 모델선택 15% / 독립감사 15%로 분리하고 각 경계에 5영업일 embargo를 둡니다. 마지막 감사 구간은 조기종료나 앙상블 가중치 결정에 사용하지 않습니다. 다음 조건을 모두 만족해야 `ML_STATUS=VALIDATED`가 됩니다.

- OOS 표본 200개 이상
- ROC-AUC 0.53 이상
- Brier score가 기저확률 예측 대비 2% 이상 개선
- 예측 상위 10%의 양성률이 전체 기저율보다 5%p 이상 높음

미통과 모델은 `ML_RAW_SCORE`만 기록하고 `ML_SCORE`, `AI_SCORE`, `W_AI`의 실효 기여를 0으로 만듭니다.

## 운영 체크리스트

- 첫 화면의 공식 종목 수와 CSV `PRODUCTION_BUY.sum()`이 같은지 확인
- 공식 0건 날 `briefing_latest.json`이 `decision: CASH`로 갱신되는지 확인
- 텔레그램이 상위 점수 종목 대신 현금 보유 메시지를 보내는지 확인
- 새 모델 학습 후 `trading_meta_v19.json.validation.reliable` 확인
- 월별 ML 순위상관이 다시 음수로 뒤집히면 모델 재승인 전까지 계속 비활성 유지
