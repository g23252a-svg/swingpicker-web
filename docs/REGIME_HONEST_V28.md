→ **랭킹은 레짐 무관 POC 근접순 유지, 레짐은 GO/NO-GO와 사이즈만 결정.**

## 4. "왜 이 종목인가" 근거 패널

원칙: **모든 근거는 실측 수치를 동반**하고, **리스크를 반드시 병기**한다.

예시 출력:
```
✓ 이 점수 구간의 과거 실측 승률 62% (표본 120건)
✓ 상승 레짐 (시장폭 60%)
✓ 거래량 밀집가 대비 +5.2% — 가치영역 근접 (실측 승률 40%)
✓ 손익비 2.1 (손절 -8.0% / 1차목표 +17.0%)
✓ AI 예측 미사용 (검증 미통과로 가중치 0 — 룰 기반 판단만 반영)
⚠ RSI 71 과열 구간
```

컬럼: `RECO_EVIDENCE` / `RECO_RISK` / `HONEST_PROB_PCT` (+레짐 4컬럼).
상세 화면 점수 영역 상단에 렌더, 점수 카드에는 착시 경고 문구 고정.
