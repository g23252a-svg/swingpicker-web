# 묵향(墨香) — 수묵 로그라이크

스마트폰 세로 화면에서 한 손으로 즐기는 턴제 던전 크롤러. 열다섯 층을 내려가
`심연의 왕`을 베면 이깁니다. 죽으면 그걸로 끝이고, 되돌아갈 층은 없습니다.

의존성 없는 단일 HTML 파일입니다. `index.html`을 브라우저에서 열면 바로 됩니다.

```bash
python3 -m http.server -d games/mukhyang 8080   # http://localhost:8080
```

## 조작

| 방법 | 동작 |
|---|---|
| 화면 쓸기 | 그 방향으로 한 칸 |
| 칸 누르기 | 그쪽으로 한 걸음 |
| 방향키 / 歇 | 이동 / 제자리 대기 |
| 물약·등유·부적 | 즉시 사용 (남은 개수 표시) |
| 운기조식 | 적이 안 보일 때 등불을 태워 회복 |
| 방향키·`.`·`Q`·`E` | 데스크톱 확인용 |

적이 있는 칸으로 움직이면 공격합니다. 계단을 밟으면 아래로 가는 버튼이 뜹니다.

## 규칙

- **등불** — 매 턴 조금씩 줄고, 줄면 시야가 좁아집니다. `등유`로 채웁니다.
  운기조식은 등불을 훨씬 빨리 태우므로 공짜 회복이 아닙니다.
- **장비** — 층마다 무기와 방어구가 한 벌씩 확실히 놓입니다. 더 좋은 것은
  자동으로 착용하고, 못한 것은 팔아 금으로 바꿉니다. 인벤토리 관리는 없습니다.
- **머무름** — 한 층에 55턴 넘게 있으면 어둠에서 새 몬스터가 기어듭니다.
- **점수** — `금 + 층×140 + 레벨×70 + 처치×12`. 최고 기록만 브라우저에 남습니다.

## 화면 읽는 법

타일은 이모지가 아니라 **한글 한 음절**입니다.

- 몬스터 — 쥐(굴쥐) 박(박쥐) 뱀(독사) 늑(들늑대) 궁(해골궁수) 골(돌골렘) 귀(원귀) 왕(보스)
- 물건 — 약(물약) 유(등유) 화(화염부) 도(도주부) 각(각성부) 검(무기) 갑(방어구) 금(금화)
- 붉은 점이 나, 붉은 고리가 계단입니다. 화폭에서 주사색은 이 둘에만 씁니다.

밝은 칸은 지금 보이는 곳, 흐린 칸은 기억만 남은 곳, 중간 톤은 아직 모르는 곳입니다.

## 난이도

BFS로 길을 찾고 위험할 때 물약·도주부를 쓰는 봇으로 40판을 돌려 맞췄습니다.

| 지표 | 값 |
|---|---|
| 도달 층 중앙값 | 12층 |
| 클리어 | 6/40 (15%) |
| 1~3층 사망 | 0건 |
| 사망이 몰리는 구간 | 13~14층 |

봇은 지도 전체를 아는 대신 전술이 단순합니다. 사람의 체감과는 다를 수 있습니다.

조정 지점은 `index.html` 상단에 모여 있습니다 — `MONSTERS` 표의 `min`/`max`(등장 층),
`spawnMonster()`의 `grow`와 공격력 계수, `generate()`의 몬스터 수, `DROPS` 가중치.

## 만든 방식

- 지도는 방 9~13개를 놓고 L자 통로로 잇습니다. 막다른 길을 줄이려 고리를 하나 더 뚫습니다.
- 시야는 8분할 재귀 그림자 투사입니다.
- 빠른 몬스터(박쥐·늑대)는 **더 빨리 다가올 뿐 한 턴에 두 번 때리지 못합니다.**
  이 제한이 없으면 늑대 한 마리가 초반 캐릭터의 체력 전부를 가져갑니다.
- 밝은 테마는 한지 위 먹, 어두운 테마는 색반전이 아니라 비석 탁본으로 따로 그렸습니다.
