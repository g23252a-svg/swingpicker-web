# 백귀야행

스마트폰 세로 화면에서 한 손으로 하는 **실시간 생존 액션**. 6분을 버티고
저승사자를 베면 이깁니다. 조작은 이동과 회피 둘뿐이고 공격은 전부 자동입니다.

```bash
python3 -m http.server -d games/baekgwi 8080   # http://localhost:8080
```

`index.html`을 파일로 바로 열어도 동작합니다. 한 장으로 합치려면:

```bash
python3 games/baekgwi/build-single.py          # baekgwi-single.html
```

## 조작

| | |
|---|---|
| 화면 아무 곳이나 대고 끌기 | 그 방향으로 달림 (뗀 자리에 조이스틱이 생김) |
| 오른쪽 아래 **회피** | 짧게 돌진. 0.3초 무적이고 **지나가며 적을 벤다** |
| 왼쪽 아래 **백귀참** | 처치로 차오르는 필살기. 화면 전체를 쓸어버린다 |
| WASD / Space / F | 데스크톱 확인용 (이동 / 회피 / 백귀참) |

### 인물

| | |
|---|---|
| **무사** | 부적으로 시작. 체력 100, 균형 |
| **무녀** | 화살로 시작. 체력 82, 이동 126, 피해 1.12배 |
| **역사** | 검기로 시작. 체력 140, 이동 94, 피해 1.15배 |

### 세 마당

| | |
|---|---|
| 1막 · 마을 어귀 | 0초~. 혼불·허수아비·도깨비. **1:48 달걀귀신** |
| 2막 · 밤 산길 | 2:05~. 해골과 불여우가 더해진다. **3:58 구미호** |
| 3막 · 저승 문턱 | 4:25~. 잡것이 사라지고 그슨대가 나온다. **6:22 저승사자** |

막마다 땅빛과 나오는 것이 바뀌고, 짧은 이야기 판이 한 번씩 끼어듭니다.

## 규칙

- 경험치 구슬을 모아 레벨이 오르면 **카드 3장 중 하나**를 고릅니다. 시간은 멈춥니다.
- 무기는 최대 6종, 각 5레벨. 부적 한 장으로 시작합니다.
- 카드는 균등 추첨이 아닙니다. **키우던 무기와 그 진화 재료**가 3.2배 자주 뜹니다.
- **3분에 구미호, 6분에 저승사자**가 나옵니다. 저승사자를 잡으면 승리입니다.
- 화면 밖으로 한참 처진 적은 조용히 사라지고 다시 앞쪽에서 나옵니다.
- 점수 = `버틴 초×10 + 처치×3 + 레벨×40`. 최고 기록만 브라우저에 남습니다.

### 무기와 진화

무기 **4단** + 짝이 되는 보조 **2단**이면 진화 카드가 뜹니다. 카드에 어떤 보조가
재료인지 적혀 있으니, 카드 고르기가 계산이 됩니다.

| 무기 | 재료 | 진화 |
|---|---|---|
| 부적 (유도) | 부채 | **만다라** — 소용돌이로 퍼지며 관통 |
| 검기 (부채꼴) | 숫돌 | **월광참** — 사방을 한 번에, 피해 2.4배 |
| 벼락 (낙뢰) | 자석 | **뇌신** — 가까운 적으로 세 번 튄다 |
| 불티 (장막) | 산삼 | **겁화** — 넓어지고 태워 죽이면 터진다 |
| 화살 (관통) | 짚신 | **백발백중** — 사방 여덟 발 |
| 방울 (궤도) | 투구 | **풍경** — 커지고 충격파를 남긴다 |

### 적

| | |
|---|---|
| 혼불·허수아비·해골 | 곧장 달려든다 |
| 도깨비 | 웅크렸다가 **돌진**한다 (점선으로 예고) |
| 불여우 | 사거리에서 멈춰 **불덩이를 뱉는다** |
| 그슨대 | 죽으면 **둘로 갈라진다** |
| 정예 | 금빛 테두리. 체력 6배, 잡으면 **보물 상자**와 넋 |

### 사건

45초 혼불 무리 · 88초 허수아비 떼 · 130초 정예 · **180초 구미호** ·
225초 해골 돌격 · 262초 정예 둘 · 310초 그슨대 무리 · **360초 저승사자**

그 사이에도 48초마다 정예가 하나씩 나옵니다.

### 넋

정예와 보스가 떨구고, 처치 25마리마다 하나씩 쌓입니다. 죽으면 남아서 시작
화면의 **넋 강화**에 씁니다 — 최대 체력, 피해, 이동 속도, 획득 범위, 치명타 확률.
이게 한 판 더 하는 이유입니다.

## 손맛

- **치명타** 13% 확률로 피해 2.3배. 금빛 숫자, 충격파, 강한 넉백이 함께 나갑니다.
- **히트스톱** 치명타와 큰 적 처치에 24~35ms 정지가 걸립니다. 잡졸까지 멈추면
  후반에 초당 수십 대를 때릴 때 렉처럼 보여서, 체력 40 초과인 적에게만 겁니다.
  최소 간격 140ms로 겹침도 막습니다.
- **콤보** 1.8초 안에 이어 잡으면 쌓이고, 쌓일수록 타격음이 반음씩 올라갑니다.
  25연속부터 글자가 붉게 달아오릅니다. 맞으면 끊깁니다.
- **슬로모션** 보스 처치(1.1초), 체력 28% 아래에서 피격(0.3초), 보스 등장(0.5초).
- 적은 사라지지 않고 **하얗게 부풀며 스러집니다**. 처치·습득·회피·발사에 각각
  다른 충격파가 퍼집니다.

## 소리

`audio.js`가 WebAudio로 직접 합성합니다. 오디오 파일은 없습니다.

- 타격음은 대역통과 노이즈 버스트와 짧은 음을 겹쳐 만듭니다. 오실레이터 하나짜리
  삑 소리로는 때린 느낌이 안 납니다.
- 배경음은 130BPM 4마디 루프(킥·스네어·하이햇·베이스)이며, 16분음표 격자에
  0.22초 앞서 예약합니다. `setInterval`로는 박자가 흔들립니다.
- 200초를 넘기거나 보스가 나오면 선율과 타악이 얹히고 음량이 올라갑니다.
- 소리가 몰리면 귀가 아프므로 종류별로 최소 간격을 둡니다(타격음 28ms 등).
- 브라우저 정책상 **첫 터치 이후에야** 소리가 열립니다. 시작 버튼을 누르는
  순간 초기화합니다.

## 만들면서 걸렸던 것

측정하지 않았으면 놓쳤을 것들입니다.

- **시작 무기가 근접이면 안 됩니다.** 검기는 사거리 76px인데 플레이어가 적보다
  빨라서, 도망치는 순간 아무것도 못 잡고 화면이 적으로 가득 찼습니다.
  유도형 부적으로 바꾸자 처치 수가 45초에 14 → 78로 올랐습니다.
- **검기는 바라보는 방향이 아니라 가장 가까운 적**을 향해 나갑니다. 도망치면서도
  베여야 합니다.
- **세로 화면에 원형 소환은 맞지 않습니다.** 좌우가 너무 멀어 가만히 서 있어도
  적이 닿는 데 10초가 걸렸습니다. 화면 비율에 맞춘 타원으로 바꿨습니다.
- **적마다 다른 궤도로 휘어 들어옵니다.** 전부 최단거리로 오면 한 덩어리로
  뭉쳐서 뒤만 따라옵니다.
- **바닥 장식은 타일이 아니라 월드 좌표 해시**로 흩뿌립니다. 타일에 큰 무늬를
  넣었더니 반복이 눈에 보였습니다.

## 난이도

플레이어 화력은 무기 레벨 × 진화 × 보조가 곱해져 기하급수로 큽니다. 적을 선형으로
올리면 후반이 산책이 됩니다. 그래서 곡선을 지수로 바꿨습니다.

| | |
|---|---|
| 적 체력 | `1.40^(초/60)` — 6분에 7.5배 |
| 적 피해 | `1.26^(초/60)` — 6분에 4.0배 |
| 적 속도 | 분당 약 +7% |
| 등장 밀도 | 180초부터 완만하게 가팔라집니다 |
| 최종보스전 | 잡것 등장을 **절반으로 줄입니다**. 물량전이 아니라 결투여야 합니다 |
| 저승사자 | 14초마다 피해 +7%, 최대 6회까지만 |

한때 360초 이후 밀도를 2.2배로 올렸는데, 경사가 아니라 **벽**이었습니다.
걷어냈습니다. 산책 방지는 밀도가 아니라 보스 자신이 해야 할 일입니다.

## 먹는 것과 맞는 것은 달라 보여야 합니다

적 탄환을 주황색 원에 흰 반사광으로 그렸더니 **경험치 구슬과 똑같이 보였습니다.**
피해야 할 것을 주우러 가게 만드는 오류였습니다.

- 적 탄환은 진행 방향으로 누운 **불덩이/혼탄 스프라이트**입니다. 붉은 경고 무리가
  깔리고 불티 꼬리를 남기며 맥동합니다.
- 습득물은 작고 둥근 보석입니다. 무리도 꼬리도 없습니다.
- 규칙: **위협은 회전하고 꼬리를 남긴다. 보상은 가만히 있다가 나에게 흘러온다.**

## 구슬은 사라지지 않습니다

성능 때문에 안 주운 구슬을 지웠더니, 후반에 경험치가 통째로 증발해 레벨업이
멎었습니다. 카드가 안 뜨니 할 일이 없어지고, 그게 3분 이후의 지루함이었습니다.

- 넘치면 **지우지 않고 멀리 있는 둘을 합칩니다.** 굵어질 뿐 총량은 그대로입니다.
- 구슬은 항상 주인 쪽으로 흘러옵니다(거리에 따라 130~340px/s). 도망치는
  플레이어가 제 경험치를 뒤에 버리고 다니던 문제를 없앴습니다.
- 고친 뒤 바닥에 남는 경험치가 4,145 → 719로 줄었고, 35초마다 2~3레벨씩
  꾸준히 오릅니다.

## 떼거리로 만드는 일

이 게임에 오래 없던 것은 "화면이 적으로 가득 차고 한 번에 여럿이 터지는" 쾌감이었습니다.

- **카메라를 1.5배 당겼습니다.** 캐릭터가 화면 폭의 9%에서 14%가 됐습니다.
- **등장 밀도를 세 배로** 올리고 한 마리 체력을 38% 낮췄습니다. 같은 시간에
  처치가 30/초 → 90/초가 됩니다.
- 무기도 커졌습니다. 검기 사거리 76 → 150px, 불티 장막 52 → 118px에
  일렁이는 테두리, 방울 최대 5개.
- 한순간에 6·14·26마리가 스러지면 그만큼 크게 터집니다.

그리기 예산을 그쪽으로 옮겼습니다. 계측해 보니 프레임당 `drawImage` 243회 중
대부분이 바닥에 깔린 구슬이었고, `fillRect` 433회는 입자였습니다.

- 바닥 구슬 상한 240 → 90 (합쳐지므로 경험치 총량은 그대로)
- 입자 340 → 150 (대신 알갱이를 키움), 피해 숫자 44 → 12
- 잡것 처치에는 시체·충격파를 붙이지 않습니다. 값나가는 처치에만 몰아줍니다
- 그림자 백여 개를 **하나의 경로로 묶어 한 번에** 칠합니다
- 무기 판정을 화면 근처 적으로만 한정했습니다 (전수 비교는 430마리)
- HUD는 매 프레임이 아니라 초당 20번, 값이 바뀔 때만 씁니다.
  `innerHTML`을 읽어 비교하면 DOM이 매 프레임 직렬화됩니다

### 성능에 대해 정직하게

이 컨테이너의 헤드리스 크로미움은 소프트웨어 렌더링이라 **직전 배포판도 같은
장면에서 44~46FPS**입니다. 새 버전은 처치량이 세 배인데 40~43입니다. 즉
최적화가 밀도 증가분을 거의 상쇄했지만, **절대 수치는 실제 기기와 다릅니다.**
휴대폰에서 버벅이면 `foeCap`과 `spawnRate`를 낮추면 됩니다.

## 확인한 것

빌드를 밀어붙이는 봇(진화 우선 → 재료 우선)으로 배속 측정했습니다.

| | |
|---|---|
| 버틴 시간 | 207 / 215 / 388 / 414초 (중앙값 6분 28초) |
| 클리어 | 1/4 |
| 판당 진화 | 평균 4.0회 |
| 도달 레벨 | 평균 38 |

판이 둘로 갈립니다. 빌드가 서면 1만 5천 처치에 진화 여섯까지 가고, 안 서면
3분쯤에 끝납니다. 선택이 결과를 가릅니다.

카드에 가중치를 주기 전에는 5판 중 3판이 "재료가 안 떠서" 2분 20초에 무너졌습니다.
어려운 것과 억울한 것은 다릅니다.

정예·상자·진화·상점·세 보스·승패 처리, 콘솔 오류 없음까지 자동으로 확인했습니다.

소리는 오디오 노드 생성 횟수를 세어 확인합니다. 효과음 13종이 모두 노드를
예약하고, 배경음이 초당 약 14개를 만들며, 음소거를 누르면 3초간 0개가 됩니다.

`game.js`의 `hpCurve` / `dmgCurve` / `spawnRate` 세 함수가 난이도 손잡이입니다.
