# 백귀야행

스마트폰 세로 화면에서 한 손으로 하는 **실시간 생존 액션**. 6분을 버티고
저승사자를 베면 이깁니다. 조작은 이동과 회피 둘뿐이고 공격은 전부 자동입니다.

```bash
python3 -m http.server -d games/baekgwi 8080   # http://localhost:8080
```

`index.html`을 파일로 바로 열어도 동작합니다. 한 장으로 합치려면:

```bash
python3 games/baekgwi/build-single.py          # baekgwi-single.html
```

## 조작

| | |
|---|---|
| 화면 아무 곳이나 대고 끌기 | 그 방향으로 달림 (뗀 자리에 조이스틱이 생김) |
| 오른쪽 아래 **회피** | 짧게 돌진, 0.3초 무적, 재사용 2.4초 |
| WASD / 방향키 / Space | 데스크톱 확인용 |

## 규칙

- 경험치 구슬을 모아 레벨이 오르면 **카드 3장 중 하나**를 고릅니다. 시간은 멈춥니다.
- 무기는 최대 6종, 각 5레벨. 부적 한 장으로 시작합니다.
- **3분에 구미호, 6분에 저승사자**가 나옵니다. 저승사자를 잡으면 승리입니다.
- 화면 밖으로 한참 처진 적은 조용히 사라지고 다시 앞쪽에서 나옵니다.
- 점수 = `버틴 초×10 + 처치×3 + 레벨×40`. 최고 기록만 브라우저에 남습니다.

### 무기와 진화

무기 **4단** + 짝이 되는 보조 **2단**이면 진화 카드가 뜹니다. 카드에 어떤 보조가
재료인지 적혀 있으니, 카드 고르기가 계산이 됩니다.

| 무기 | 재료 | 진화 |
|---|---|---|
| 부적 (유도) | 부채 | **만다라** — 소용돌이로 퍼지며 관통 |
| 검기 (부채꼴) | 숫돌 | **월광참** — 사방을 한 번에, 피해 2.4배 |
| 벼락 (낙뢰) | 자석 | **뇌신** — 가까운 적으로 세 번 튄다 |
| 불티 (장막) | 산삼 | **겁화** — 넓어지고 태워 죽이면 터진다 |
| 화살 (관통) | 짚신 | **백발백중** — 사방 여덟 발 |
| 방울 (궤도) | 투구 | **풍경** — 커지고 충격파를 남긴다 |

### 적

| | |
|---|---|
| 혼불·허수아비·해골 | 곧장 달려든다 |
| 도깨비 | 웅크렸다가 **돌진**한다 (점선으로 예고) |
| 불여우 | 사거리에서 멈춰 **불덩이를 뱉는다** |
| 그슨대 | 죽으면 **둘로 갈라진다** |
| 정예 | 금빛 테두리. 체력 6배, 잡으면 **보물 상자**와 넋 |

### 사건

45초 혼불 무리 · 88초 허수아비 떼 · 130초 정예 · **180초 구미호** ·
225초 해골 돌격 · 262초 정예 둘 · 310초 그슨대 무리 · **360초 저승사자**

그 사이에도 48초마다 정예가 하나씩 나옵니다.

### 넋

정예와 보스가 떨구고, 처치 25마리마다 하나씩 쌓입니다. 죽으면 남아서 시작
화면의 **넋 강화**에 씁니다 — 최대 체력, 피해, 이동 속도, 획득 범위, 치명타 확률.
이게 한 판 더 하는 이유입니다.

## 파일

| | |
|---|---|
| `index.html` | 화면 구조와 UI 스타일 |
| `sprites.js` | 도트 스프라이트 자료. `'.'`은 투명, 나머지는 팔레트 키 |
| `audio.js` | 소리. 효과음 13종과 배경음 |
| `game.js` | 게임 본체 |
| `build-single.py` | 위 넷을 한 파일로 합침 |

스프라이트를 고칠 때는 각 행의 길이가 같은지, 쓰인 글자가 팔레트에 있는지
확인하세요. 없는 글자를 쓰면 굽는 단계에서 조용히 투명해집니다.

## 손맛

- **치명타** 13% 확률로 피해 2.3배. 금빛 숫자, 충격파, 강한 넉백이 함께 나갑니다.
- **히트스톱** 치명타와 큰 적 처치에 24~35ms 정지가 걸립니다. 잡졸까지 멈추면
  후반에 초당 수십 대를 때릴 때 렉처럼 보여서, 체력 40 초과인 적에게만 겁니다.
  최소 간격 140ms로 겹침도 막습니다.
- **콤보** 1.8초 안에 이어 잡으면 쌓이고, 쌓일수록 타격음이 반음씩 올라갑니다.
  25연속부터 글자가 붉게 달아오릅니다. 맞으면 끊깁니다.
- **슬로모션** 보스 처치(1.1초), 체력 28% 아래에서 피격(0.3초), 보스 등장(0.5초).
- 적은 사라지지 않고 **하얗게 부풀며 스러집니다**. 처치·습득·회피·발사에 각각
  다른 충격파가 퍼집니다.

## 소리

`audio.js`가 WebAudio로 직접 합성합니다. 오디오 파일은 없습니다.

- 타격음은 대역통과 노이즈 버스트와 짧은 음을 겹쳐 만듭니다. 오실레이터 하나짜리
  삑 소리로는 때린 느낌이 안 납니다.
- 배경음은 130BPM 4마디 루프(킥·스네어·하이햇·베이스)이며, 16분음표 격자에
  0.22초 앞서 예약합니다. `setInterval`로는 박자가 흔들립니다.
- 200초를 넘기거나 보스가 나오면 선율과 타악이 얹히고 음량이 올라갑니다.
- 소리가 몰리면 귀가 아프므로 종류별로 최소 간격을 둡니다(타격음 28ms 등).
- 브라우저 정책상 **첫 터치 이후에야** 소리가 열립니다. 시작 버튼을 누르는
  순간 초기화합니다.

## 만들면서 걸렸던 것

측정하지 않았으면 놓쳤을 것들입니다.

- **시작 무기가 근접이면 안 됩니다.** 검기는 사거리 76px인데 플레이어가 적보다
  빨라서, 도망치는 순간 아무것도 못 잡고 화면이 적으로 가득 찼습니다.
  유도형 부적으로 바꾸자 처치 수가 45초에 14 → 78로 올랐습니다.
- **검기는 바라보는 방향이 아니라 가장 가까운 적**을 향해 나갑니다. 도망치면서도
  베여야 합니다.
- **세로 화면에 원형 소환은 맞지 않습니다.** 좌우가 너무 멀어 가만히 서 있어도
  적이 닿는 데 10초가 걸렸습니다. 화면 비율에 맞춘 타원으로 바꿨습니다.
- **적마다 다른 궤도로 휘어 들어옵니다.** 전부 최단거리로 오면 한 덩어리로
  뭉쳐서 뒤만 따라옵니다.
- **바닥 장식은 타일이 아니라 월드 좌표 해시**로 흩뿌립니다. 타일에 큰 무늬를
  넣었더니 반복이 눈에 보였습니다.

## 확인한 것

390×844 (dpr 2) 화면에서 자동 조작 봇으로 측정했습니다.

| 시점 | 살아있는 적 | 누적 처치 | 레벨 | FPS |
|---|---|---|---|---|
| 30초 | 13 | 35 | 4 | 60 |
| 60초 | 26 | 96 | 9 | 60 |
| 120초 | 95 | 247 | 15 | 60 |

적 상한은 260마리이며 그 부근에서도 60FPS를 유지합니다. 레벨업 카드, 두 보스의
등장, 승리·사망 처리, 콘솔 오류 없음까지 자동으로 확인했습니다.

소리는 오디오 노드 생성 횟수를 세어 확인합니다. 효과음 13종이 모두 노드를
예약하고, 배경음이 초당 약 14개를 만들며, 음소거를 누르면 3초간 0개가 됩니다.
